# SBOM & CVE Sample — numaker-som-ma35d16a81 (Yocto 5.0)

This directory contains sample **SBOM (Software Bill of Materials)** and **CVE scan**
artifacts generated by the Yocto 5.0 build for the `numaker-som-ma35d16a81` machine
(image: `core-image-minimal`), based on Linux kernel **6.12.104-cip30-6.12.y**
(meta-ma35d1 layer, PV `6.12.y+git`).

These are the aggregated, image-level reports produced automatically by the Yocto
build (via the `cve-check` and `create-spdx` classes). They are provided here as a
representative sample for FAE review, instead of the full raw `deploy/spdx/` and
`deploy/cve/` directories, which contain thousands of per-recipe/per-package
intermediate files used to generate these summaries.

## Files

| # | File | Description | Size |
|---|------|-------------|------|
| 1 | `core-image-minimal-numaker-som-ma35d16a81.rootfs.manifest` | **Software manifest**: list of all packages included in the image, with architecture and version — one line per package. Simplest, most human-readable inventory. | ~5 KB |
| 2 | `core-image-minimal-numaker-som-ma35d16a81.rootfs.cve` | **CVE report**: CVE scan results for every package in the image, including CVSS v2/v3/v4 scores, vector, status (Patched/Unpatched), and NVD reference link. Plain text format. | ~600 KB |
| 3 | `core-image-minimal-numaker-som-ma35d16a81.rootfs.spdx.tar.zst` | **Official SBOM in SPDX 2.3 format** (compressed archive). Industry-standard SBOM covering the full image; this is the format typically requested for compliance/audit purposes. | ~625 KB |
| 4 | `recipe-core-image-minimal.spdx.json` | **SPDX top-level document** for the image recipe. Serves as an index describing which recipes make up the image and referencing the other SPDX documents. Not required for review, but useful to confirm completeness/traceability of the SBOM. | ~2 KB |

## Notes

- Source paths in the Yocto build tree (`tmp-glibc/deploy/`):
  - `images/numaker-som-ma35d16a81/core-image-minimal-numaker-som-ma35d16a81.rootfs.{manifest,cve,spdx.tar.zst}`
  - `spdx/numaker_som_ma35d16a81/recipes/recipe-core-image-minimal.spdx.json`
- The original files in `deploy/images/.../` are symlinks pointing to timestamped
  build artifacts (e.g. `...-20260907031603.cve`); the copies here are the
  resolved, real file contents (not symlinks).
- To extract the SPDX archive:
  ```sh
  tar --zstd -xf core-image-minimal-numaker-som-ma35d16a81.rootfs.spdx.tar.zst
  ```
- CVE status in the `.cve` file reflects Yocto's `cve-check` metadata matching at
  build time; entries marked `Unpatched` should be manually reviewed, as some may
  be false positives due to version-string mismatches between upstream NVD records
  and backported/CIP kernel patches.
